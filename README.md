# [Название] — музыкальная платформа в духе SoundCloud

Showcase-проект: лента треков, плеер с волной, комментарии на таймлайне, плейлисты и загрузка своих треков. Всё работает прямо в браузере, без сервера.

**Демо:** https://alexstaaa.github.io/music-player/

## Возможности

- **Плеер** — очередь, перемешивание, повтор, громкость, продолжение с того же места после перезагрузки, медиа-клавиши и экран блокировки (Media Session API)
- **Волна** — перемотка перетаскиванием, время под курсором, аватары комментариев на таймлайне
- **Демо-музыка генерируется в браузере** — у каждого жанра свой синтезатор на Web Audio API; никаких аудиофайлов и лицензий, результат кэшируется в IndexedDB
- **Социальное** — лайки, репосты, подписки, комментарии с привязкой ко времени
- **Плейлисты** — создание, переименование, добавление и удаление треков
- **Загрузка** — свой аудиофайл (MP3, WAV, OGG, M4A, FLAC), волна строится из реального звука
- **Поиск** по названию, артисту, тегам и жанрам; **библиотека** с историей прослушиваний
- **Жидкое стекло** на плеере и навигации — преломление по краям в Chromium, обычное размытие в остальных браузерах
- Тёмная и светлая темы, русский и английский языки, адаптивная вёрстка
- Горячие клавиши: `Пробел` пауза · `←/→` перемотка · `Shift+←/→` трек · `M` звук · `L` лайк · `/` поиск

> Данные (профиль, лайки, плейлисты, загрузки) хранятся только в IndexedDB вашего браузера. Слой `src/db/api.ts` сделан так, чтобы позже его можно было заменить на настоящий бэкенд.

## Стек

| | |
|---|---|
| Сборка | Vite 8, pnpm |
| UI | React 19 + React Compiler, TypeScript |
| Роутинг | TanStack Router (hash-история для GitHub Pages) |
| Стили | Tailwind CSS 4, дизайн-токены в CSS-переменных |
| Компоненты | Base UI, Sonner |
| Данные | Dexie (IndexedDB) + live queries, Zustand |
| Аудио | HTMLAudioElement, Web Audio API (OfflineAudioContext) |
| Локализация | Paraglide JS |
| Качество | Biome |
| Деплой | GitHub Actions → GitHub Pages |

## Запуск

Нужен Node.js 24+ и pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # сборка в dist/ + проверка типов
pnpm check      # линтер и форматирование
```

Каждый push в `main` собирает и публикует сайт через `.github/workflows/deploy.yml`.

## Структура

```
src/
  audio/       синтезатор демо-треков, аудиодвижок, работа с буферами
  db/          схема IndexedDB, стартовые данные, API (чтение и запись)
  components/  плеер, волна, жидкое стекло, карточки, меню, диалоги
  routes/      страницы: лента, трек, артист, плейлист, поиск, библиотека, загрузка
  stores/      состояние плеера, настройки, диалоги
messages/      переводы ru / en
design/        исходники макетов и дизайн-системы
```
